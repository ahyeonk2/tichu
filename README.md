# TICHU — Interactive Rule Map

모바일 우선의 인터랙티브 노선 포스터. React 19 + TypeScript + Vite 6 + Tailwind CSS 4 + Motion for React.

## 실행

Node.js 22 이상을 설치한 환경에서 이 폴더를 터미널로 엽니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. pnpm 사용 시 `pnpm install && pnpm dev`도 가능합니다.

```sh
npm run build
npm run preview
```

`dist/`는 정적 호스팅 가능한 배포 결과물입니다. HTML 파일을 직접 여는 대신 개발 서버 또는 정적 서버를 사용하세요.

## 구현

- 시작 전 소개 / 준비 / 플레이 / 점수 계산
- 원본 좌표계와 SVG 인스턴스 하나, 정확히 연결되는 3개의 path
- 전체 지도와 구간 확대는 viewBox만 전환; 경로 데이터 변경 없음
- 650ms 카메라 전환, 단계별 배율 의미 변화
- 스크롤에 따른 실제 path 길이 측정과 dashoffset 갱신, requestAnimationFrame 사용
- 반복 경로, 라지·스몰 선언 분기, 일반 종료와 원투의 대체 분기
- 짧은 기본 규칙, 23개 규칙 상세, 카드 조합 6종과 비교·점수 그래픽
- 검색 결과 → 해당 구간 및 노드 좌표 → 상세 바텀시트
- 내부 스크롤, 바깥 스크롤 잠금, Escape 닫기, 포커스 가두기와 복귀
- 전체 지도 복귀 시 기존 스크롤 복원, 브라우저 뒤로 가기로 이전 카메라 복원
- 키보드 노드 조작, 스크린 리더 레이블, 44px 이상 노드 터치 영역(393px 기준)
- reduced-motion, safe-area 및 동적 뷰포트 대응

## 구조

- `src/data/mapData.ts`: 고정 좌표와 SVG 경로
- `src/data/rules.ts`: 규칙·예시·검색 키워드·출처
- `src/data/theme.ts`: 색상과 단계 범위
- `src/hooks/useMapCamera.ts`: 카메라·히스토리·위치 복귀
- `src/hooks/useRouteProgress.ts`: 스크롤 기반 경로 그리기
- `src/components/RouteMap.tsx`: 동일 SVG 지도와 의미적 확대
- `src/components/RuleBottomSheet.tsx`: 접근 가능한 상세 시트
- `src/components/RuleSearch.tsx`: 검색과 질문 바로가기
- `src/components/PlayingCard.tsx`, `CardCombination.tsx`: CSS 카드 그래픽

## 검증과 범위

393 × 852 Chrome 및 1440px 데스크톱 자동 브라우저 검사: 동일 경로 유지, 플레이 확대, 카드 비교 열기·닫기, 스크롤 위치 복원, 검색→폭탄 상세, 가로 넘침 없음, 런타임 오류 없음. TypeScript 검사와 프로덕션 빌드 수행.

실제 iOS Safari·Android 기기와 스크린 리더 실기기 검사는 수행하지 않았습니다. 전체 지도에서 두 손가락을 벌리면 같은 SVG가 확대됩니다. 125% 이상 확대하고 손을 떼면 해당 구간의 상세 규칙을 표시합니다. 큰 단계 노드의 단일 탭은 전환하지 않습니다. 하단 탐색은 키보드와 한 손 조작을 위한 대체 수단입니다. 자유 드래그 카메라는 제공하지 않습니다. 실제 게임 진행, 계정, 서버, 점수 입력 계산기는 범위에 포함하지 않습니다.

## 모바일 서비스 개편

첫 진입은 간결한 소개와 바로 이어지는 지도로 구성합니다. 전체·준비·플레이·점수·검색의 하단 고정 탐색을 제공하며, 상단에 현재 구간과 전체 지도 복귀를 유지합니다. 데스크톱에서도 최대 480px 서비스 폭을 유지합니다. 확대 상태의 본문 크기를 키웠고 큰 홍보형 타이틀과 종료 배너를 제거했습니다. 360px·393px Chrome에서 탐색·검색·시트 복귀·가로 넘침을 확인했습니다.

## Figma 홈 화면

홈은 `수련의방 / iPhone 17 - 6` (`187:1239`)의 402×874 좌표를 기준으로 구현했습니다. 원본 그래픽 17개 파일은 `public/figma/`, 동일 폰트는 `public/fonts/`에 저장되어 임시 Figma URL 없이 로딩됩니다. 홈의 배너·탭을 제거하고 원본 구성을 유지합니다. 기존 핀치 요구사항에 따라 안내 문구의 ‘눌러보세요’만 ‘확대해보세요’로 변경했습니다.

`src/data/figmaHome.ts`는 원본 그래픽의 위치·크기·회전 및 구간 카메라를 관리합니다. 홈과 확대는 같은 SVG와 그래픽을 공유하고 viewBox만 바뀝니다. 전체 규칙과 검색·상세 시트는 유지하며, 확대 구간 아래에서 기본 설명을 바로 읽을 수 있습니다. 홈의 팀 분배·카드 분배·티츄·조합내기·특수카드·승리 항목은 상세 시트와 연결됩니다. 키보드 사용자는 Tab으로 확대 탐색 메뉴를 표시할 수 있습니다.

검증: 402×874 원본 비교 및 각 그래픽의 실제 렌더링 크기 확인, 393px 가로 넘침 없음, 팀 구성→닫기, 특수카드→용, 핀치→준비 확대, 전후 동일 경로, 런타임 오류 없음. iOS Safari 실기기는 미검증입니다.

## Figma 준비 구간 (17-6 / 17-7 / 17-8 / 17-9)
- 홈의 시작하기 부근에서 두 손가락을 벌리면 같은 SVG 좌표계를 4배 확대합니다. 단일 탭으로 화면을 전환하지 않습니다.
- 확대 지도에서 아래로 스크롤하면 카드 분배와 선언 구간이 이어집니다. 홈 카드 분배 부근에서 확대하면 바로 해당 위치로 이동합니다.
- 라지티츄·스몰티츄 버튼은 독립적으로 인라인 설명을 펼치고 접습니다. 각 선언은 본인이 1등으로 카드를 소진해야 성공합니다.
- 좌측 상단 화살표 또는 브라우저 뒤로 가기로 전체 지도에 돌아갑니다. 키보드 탐색 메뉴도 유지합니다.
- Figma의 플레이 시간 오타를 60분으로 수정하고, 첫 8장 이후 남은 6장을 받는 단계를 보충했습니다.
- 모바일 Chromium 터치 시뮬레이션에서 탭/핀치 구분, 연속 스크롤, 직접 확대, 독립 토글, 원본 경로 유지 및 393px 가로 넘침을 검증했습니다. 실제 iOS 기기 검증은 미실시입니다.

## 최신 인터랙션 변경
이 절의 동작이 위의 이전 바텀시트/단일 탭 설명을 대체합니다.
- 모든 홈 노드와 규칙 버튼은 지도 확대 화면으로 연결됩니다. 규칙 상세 및 검색에서 바텀시트를 사용하지 않습니다.
- 시작하기·팀 분배·카드 분배는 기존 Figma 확대 지도를 사용합니다. 선언·플레이·특수카드·점수 규칙은 같은 민트색 노선과 타이포그래피의 확대 화면으로 연결됩니다.
- 설명의 페이드인은 사용자의 아래 방향 터치 스크롤·휠·키보드 스크롤에서만 시작합니다. 자동 카메라 이동으로는 실행하지 않습니다.
- 17-8 카드 그림: 첫 8장, 교환 전 14장(8+6)을 75ms 간격으로 순차 등장시킵니다. 17-7 팀 구성 그림은 유지합니다.
- 모션 감소 설정에서는 내용을 즉시 표시합니다. 모바일 Chromium에서 줌 진입 시 숨김, 스크롤 후 순차 등장, 바텀시트 없음, 393px 가로 넘침 없음, 모션 감소 처리를 검증했습니다.

### 선언 예외 — 17-9 인라인 펼침
라지티츄와 스몰티츄는 확대 화면 전환의 예외입니다. 카드 분배 지도에서 각각 독립적으로 펼치고 접으며, 카메라·스크롤·브라우저 방문 기록을 변경하지 않습니다. 홈이나 관련 규칙에서 선언을 선택해도 카드 분배 지도 안의 해당 설명을 엽니다. 카드 14장 그림은 설명 펼침에 맞춰 아래로 이동합니다.

## 最新 홈·플레이·점수계산
- 첫 방문에만 두 단계 안내: 세 주요 단계 외 블러 → 빨간 추가 규칙 안내. 완료 여부는 기기 localStorage에 저장합니다.
- 홈 17-6의 라운드 곡선에 움직이는 점선을 추가했습니다. 모션 감소 설정에서는 정지합니다.
- 확대 직후 화면에 있는 내용은 즉시 표시합니다. 화면 밖 설명·카드만 아래 방향 스크롤로 페이드인/순차 등장합니다.
- 홈 2는 Figma 17-10의 플레이 화면입니다. 참새(숫자 1) 시작, 패스, 같은 종류·장수의 더 높은 카드 비교를 표시합니다.
- 조합내기는 기본 조합/폭탄 탭, 특수카드는 봉황/용/개/참새/폭탄 탭의 바텀시트입니다. 01~06 번호와 개별 설명을 각 조합에 붙였습니다.
- 라지·스몰 티츄는 예외로 지도에서 인라인 펼침을 유지합니다.
- 홈 3은 점수계산입니다. 트릭 정의, 카드별 점수, 마지막 카드 처리, 원투/선언, 1,000점 미달 시 반복 및 동점 처리를 설명합니다.
- 1000점!은 클릭 없는 표시입니다. 독립 승리 화면으로 연결하지 않습니다.
- 검증: 393×852 Chromium 모바일 시뮬레이션에서 첫 방문 안내·지속 저장, 첫 화면 즉시 표시, 오프스크린 페이드인, 카드 stagger, 모든 탭, 시트 닫기 후 지도 위치 유지, 선언 독립 토글, 가로 넘침 없음을 확인했습니다. 실제 iOS 기기 검증은 미실시입니다.

### 카드 이미지와 간결한 조합 설명
- 첨부한 용·봉황·개 원본 이미지를 특수카드 바텀시트에 반영했습니다. 참새도 기존 카드 이미지를 표시합니다. 특수카드 탭에서 폭탄을 제거하고 조합내기에만 남겼습니다.
- 기본 조합의 구성 설명은 제목 옆에 배치했습니다. 개별 승패 비교 설명은 제거했습니다.
- 플레이 3·3은 고정하고 5·5만 순차 등장합니다. 모션 감소 설정에서는 모두 즉시 표시합니다. 플레이의 다시 시작 설명을 제거했습니다.
- 점수계산의 원투와 선언을 원투 설명으로 줄였습니다. 첫 방문 안내를 왼쪽의 작은 패널로 조정했습니다.

### 최신 정리
- 홈 점선은 아래에서 위로 이동합니다. 첫 방문 안내는 세 주요 구간 외 블러와 지도 위의 두 문구로 표시하며, 수정 안내는 v2 저장 키로 한 번 다시 제공합니다.
- 폭탄은 특수카드 바텀시트에만 있습니다. 용·봉황·개는 첨부 PNG를 Vite 정적 자산 import로 포함해 해시 경로로 배포합니다.
- 카드 내기 문구는 “같은 조합이면서 더 큰 수를 냅니다”입니다.
- 조합내기·특수카드 버튼의 시각 크기를 줄이고 44px 터치 영역은 유지합니다.

### 특수카드 역할과 교환 모션
특수카드 이미지 오른쪽에 소개와 굵은 역할 설명을 배치했습니다. 카드 교환은 14장 중 3장이 회색으로 바뀐 뒤 새 핑크 카드 3장이 들어오는 애니메이션이며, 마지막 카드 수는 14장입니다. 모션 감소 환경에서는 완료 상태를 즉시 보여줍니다.
